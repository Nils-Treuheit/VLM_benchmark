PROTOCOL

Scene graph detection from pixels

Models receive images and dataset vocabularies, then return object labels, normalized boxes, and directed relations. Objects match one-to-one at IoU ≥ 0.5. A relation counts only when both endpoints and its directed predicate match.

Invalid JSON and runtime failures remain in each panel denominator. PSG uses boxes and is labeled box-adapted SGG; it is not the official mask-grounded PSG score. Source provenance, predicate supports, full metrics, and limitations are in the Markdown report.
