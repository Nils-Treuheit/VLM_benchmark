BENCHMARK METHOD

What each task measures

AI2D · DIAGRAM REASONING

Test set, 100 of 3,088

Each sampled item contains one diagram image, a four-choice question, and four answer options. Models are asked to return only the option letter.

Score: exact letter accuracy. Missing or unparsable letters count as incorrect.

AI2D dataset card ↗

TEXTVQA · TEXT IN IMAGES

Validation, 100 of 5,000

Each sampled item contains one natural image, an open question, and human answer references. Models are asked for the shortest exact text visible in the image.

Score: answers are normalized, then each human reference is held out in turn. The prediction earns one third per matching remaining reference, capped at one; the final score averages those trials.

TextVQA dataset card ↗

VQAv2 · YES / NO

Validation, 25 questions

Questions are drawn from the yes/no answer type to test truth judgments about visible content.

Score: normalized human-answer consensus.

VQAv2 official data ↗

VQAv2 · COUNTING

Validation, 25 questions

Questions have the number answer type and begin with “How many”.

Score: normalized human-answer consensus.

VQAv2 · VISUAL DESCRIPTION

Validation, 25 questions

Open “other” questions are filtered to direct questions about visible objects, attributes, and scenes.

Score: normalized human-answer consensus.

PERCEPTAX · AFFORDANCE

Real test split, 25 questions

Questions cover object affordance, intended function, and repurposing in real images.

Score: normalized answer match. Question-type scores remain available in the source dataset.

PercepTax dataset ↗

NEGVQA · NEGATION

Dev split, 25 questions

Each item asks a negated two-choice question. Models return A or B.

Score: exact option accuracy; an unparsable answer is incorrect.

NegVQA paper ↗ · Dataset ↗

GRAB-LITE · SCIENTIFIC-GRAPH VQA

Full test split, 500 questions

One scientific graph image per question, balanced across properties, functions, series, transformations, and real figures. Models answer questions about the graph.

Score: normalized exact-match accuracy, overall and by task. This evaluates graph-image understanding through VQA; it does not evaluate scene-graph generation.

GRAB benchmark ↗ · GRAB-Lite data ↗

Sampling: 100 examples for AI2D and TextVQA. Each new VQA category uses 25 fixed examples, sampled with seed 3407 and reused across models.

Panel total: the six VQA category scores are averaged equally. This macro average is a local comparison measure; it is not an official score from any one source dataset.

Runtime: requests run serially, one image and one request at a time. The generation limit is 256 tokens, or 2,048 for Thinking models. Observed whole-GPU peak includes desktop baseline. Mean seconds is per generation call; output tokens/second divides generated tokens by that call time.

Context: model runs use their listed configured context. Q8 KV-cache memory profiles estimate 8K/default/maximum fit under a 30 GiB budget; edge tables add a 1 GiB desktop reserve. They are not additional edge-device accuracy runs.

Answer handling: Thinking text is removed before scoring. AI2D and NegVQA use the final answer letter; open answers are normalized before consensus scoring.
