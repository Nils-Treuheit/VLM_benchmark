Edge Limited measurement disclaimer

Current scores come from completed benchmark runs, but the current edge rankings have not all been rerun under the selected VRAM limit. Edge eligibility and context evidence use different measurements across suites:

  • Qwen-VL: task scores and benchmark peaks are measured at their recorded run context. The estimated 8K residency includes a 1 GiB desktop reserve; maximum context under 8, 10, 12, 14, or 16 GiB is interpolated from the context profile. These edge-context values are estimates, and measured benchmark peaks can exceed the selected limit.
  • LLaVA and Φ-Vision: task scores and maximum process-local peak VRAM across the benchmark tasks are measured. The checkpoint context shown is advertised metadata; no context sweep established a maximum under each VRAM limit.
  • Cosmos: task scores and peak whole-device VRAM, including desktop use, are measured. Cosmos3-Nano records a 16,384-token run cap; other runs use the checkpoint default. A configured run cap is not a measured maximum context under an edge limit.
  • Other Big VLMs: task scores and process-local peak VRAM are measured. Checkpoint context is metadata; per-request context and edge-context sweeps are not recorded.

Working hypothesis for refinement: With model, inputs, context length, precision, and decoding held fixed, a VRAM ceiling alone should have little effect on answer quality; it mainly affects fit and speed. More context uses more KV-cache memory and can help or hurt task scores. We expect smaller context-driven changes on these mostly single-image tasks than on multi-image, video, or long-prompt tasks. This is a hypothesis to test, not a result established by current reports. See the KV-cache documentation and long-context retrieval study.

Until selective edge refinement is complete, treat these rankings as candidate screening, not as measured quality at the selected VRAM limit. The final Edge Limited results will include only scores, peak VRAM, and context limits measured in runs performed under that limit. See the selective edge refinement plan.
