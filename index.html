Edge Limited measurement disclaimer

Results are ranked among candidates with verified cap-specific measurements. Blocked and unavailable candidates remain excluded. A model qualifies for the overall ranking only after a complete shared-task run and its real-image context probe both pass under the same measured whole-device limit. Category rows require complete coverage for their listed task. See the linked refinement record for candidate outcomes.

  • Existing suite scores and memory records screen candidates only; they do not establish that a run fits any selected cap.
  • Candidate context must be measured with the model's real image path. Checkpoint metadata and estimated KV-cache profiles do not qualify.
  • A stage with no verified cap-specific run displays an explicit empty state.

Working hypothesis for refinement: With model, inputs, context length, precision, and decoding held fixed, a VRAM ceiling alone should have little effect on answer quality; it mainly affects fit and speed. More context uses more KV-cache memory and can help or hurt task scores. We expect smaller context-driven changes on these mostly single-image tasks than on multi-image, video, or long-prompt tasks. This is a hypothesis to test, not a result established by current reports. See the KV-cache documentation and long-context retrieval study.

No provisional estimates are shown as Edge Limited results. See the selective edge refinement plan for the run protocol and current execution status.
