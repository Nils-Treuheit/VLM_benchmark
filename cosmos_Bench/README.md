# Cosmos VLM benchmark

This suite compares locally cached Cosmos vision-language checkpoints on the shared image tasks from the [Qwen-VL benchmark](../qwenVL_Bench/README.md).

The completed report covers five Cosmos checkpoints across eight task groups, with fixed samples, task scores, runtime, and memory use. See the [results report](report.md) or open the [interactive report](index.html).

The benchmark uses local model files and evaluates serially in host context. Setup and runner details are in the local `README.agent.md` notes.
