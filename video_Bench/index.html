SHARED VIDEO INPUT

Up to 16 source-timestamped frames

Targets span the source timeline. The nearest decoded frame is selected for each target, with earlier timestamps breaking ties. Duplicate or non-increasing PTS values are omitted; source timestamps are never synthesized.

Decode: sequential through 120 seconds; backward keyframe seek for longer clips. Original resolution is retained until each pinned model processor runs.

MODEL TRACK COVERAGE

Four requested checkpoints

InternVideo3, LLaVA-NeXT-Video, and VideoChat3 run both tracks. TimeLens2 runs VUE-TR temporal retrieval.

Execution: pinned local checkpoints, one model at a time, temperature zero.

Sampling: policy `video_visual_uniform16_source_pts_seek_v2`; seed 3407 for both fixed manifests. Identical selected frames are reused across assigned models.

Temporal parsing: numeric or numeric-string endpoint pairs and a top-level pair are accepted. Malformed outputs count as empty predictions and are reported as parse failures.

Task compatibility: TimeLens2 produces temporal intervals, so it is evaluated on VUE-TR and has no MVBench choice score.

Data handling: video files, query annotations, and per-item outputs remain local. This page contains aggregate scores only.

Limitations: the MVBench sample excludes fine-grained pose. VUE-TR reports the vision-only subset supported by all four adapters.
